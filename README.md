# telecommande-ir

Telecommande IR universelle pour Raspberry Pi avec Game HAT (fichiers .ir au format Flipper Zero).

Application du projet Raspberry Pi "RLE" (Kali Linux, Waveshare Game HAT).

## Donnees IR

Le dossier `ir/IRDB` reprend la base communautaire **Flipper-IRDB**
(https://github.com/Lucaslhm/Flipper-IRDB), sous sa licence d'origine.
